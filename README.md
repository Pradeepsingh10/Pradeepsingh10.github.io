# Portfolio

Static portfolio site. All content lives in `projects.js`.

## Add a new project
1. Put screenshots in `images/`.
2. Open `projects.js`, copy a block inside `PROJECTS`, paste it and edit.
3. Commit and push. The site updates automatically.

## Publish on GitHub Pages (free)
1. Create a repo named `<your-username>.github.io` and upload all these files (index.html at the root).
2. Repo Settings > Pages > Source: "Deploy from a branch" > branch `main`, folder `/ (root)`.
3. Your link: `https://<your-username>.github.io`

Add your GitHub, LinkedIn and resume PDF links in `PROFILE` inside `projects.js`.
